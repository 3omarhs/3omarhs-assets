# Upscale Studio model weights

Unmodified x2, x4 and x8 ESRGAN Slim TensorFlow.js models from `@upscalerjs/esrgan-slim@1.0.0`, distributed under the accompanying MIT license. Source project: https://github.com/thekevinscott/UpscalerJS.

Only the public model JSON and weights are hosted here. Visitor images and enhanced outputs are never uploaded to this repository. Application references are pinned to an immutable Git commit.
