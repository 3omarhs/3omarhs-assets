# Illustrated arcade release r1

Original artwork generated with the built-in image generation tool for the 3omar.hs games portal, October2026. No third-party game artwork was downloaded.

- 107 individual illustrated covers: 105 solo games and 2 party companions.
- Five sprite atlases containing 160 objects and materials, plus standalone WebP sprites.
- 16 painted environment backgrounds.
- Technical processing: cell extraction, alpha-bound cropping and WebP encoding.

Prompt set: each sprite atlas requested an exact6x6transparent grid of named, isolated objects, with polished tactile soft3D/painted materials, complete silhouettes, generouspadding,no labels/UI/borders. Atlas0characters,sheep/wolves,cannons,sports,fruit/space; atlas1adventurers,vehicles,terrain,skill,food/royalty; atlas2gems,puzzle/board,sports,materials; atlas3isometriccity,animals,legacycharacters,vehicles,snipers. Backgroundatlas requested4x4empty-center genre environments. Coveratlases requested4x4landscape professional gamekeyart, no typography/UI, eachcell matching game name/genre. Appgames/includes/art-cover-order-r1.json supplies exact ordered game subjects; final sheetmapped manually for an extra inserted illustration.

The fifth atlas supplies quiet interface materials and grass, soil, water and asphalt surfaces. Four replacement covers correct the depicted rules for Three in Row, Tower Hopper, Rope Rescue and Sand Blast.

Raster game objects are separate from input, collision and simulation rules and text. Sprite alpha dimensions are in sprites.json; application crop coordinates are tracked separately in art-sprites-r1.json.
